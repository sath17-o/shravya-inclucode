# Phase 2A legacy curriculum policy

Phase 1 was an unreleased foundation. No production learner or teacher curriculum migration is required.

Phase 2A final invariants take priority over speculative backward compatibility. Development databases are clean; a populated pre-release curriculum database must be reset before upgrading. Shravya does not fabricate definitions, ordering, concept keys, source types, translations, review state, or provenance.

Compatible non-curriculum records may survive. A future released version would require an explicit teacher-assisted data-upgrade workflow.
