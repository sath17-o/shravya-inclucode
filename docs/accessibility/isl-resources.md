# Optional external ISL educational resources

## Purpose

Shravya may provide an optional link to an authoritative external Indian Sign Language (ISL) educational resource for an exact approved academic term. The core classroom lesson remains usable without the external resource.

## Core boundary

Teachers approve the classroom term and definition. An external ISL resource is separately attributed and is not marked teacher-approved. It is supplementary to the canonical academic term, teacher-approved definition, and approved Malayalam explanation.

## Privacy and connectivity

Opening the lesson or the definition does not make a YouTube request. A request occurs only when the learner activates the external link. The destination opens in a new tab, requires internet access, and takes the learner outside Shravya’s controlled environment.

## Accessibility limitation

This one vocabulary resource is supplementary. It does not provide full interpretation, does not replace an interpreter, does not make automatic transcription equivalent to language access, and is not generated by Shravya.

## Fail-closed mapping

The link is shown only when the exact selected context ID, context version, and glossary-term ID in the registry match. It does not match by visible text, aliases, definitions, Malayalam labels, or lesson prose.

## Removal procedure

Remove or disable the record if the URL no longer resolves, source authority cannot be confirmed, attribution changes, content changes materially, the mapping is disputed by a qualified reviewer, reuse or linking conditions change, or the resource becomes unsuitable or inaccessible.

## Review responsibility

Each future resource requires an exact authoritative URL, source attribution, access date, context-bound glossary mapping, licensing/linking review, specialist review where possible, and explicit tests.
