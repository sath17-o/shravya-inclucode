# Interface rules

Phase 1 implements the shared shell rules that later features must preserve:

- keyboard-first interaction with visible focus;
- a skip-to-content link and logical landmarks;
- Malayalam-first bilingual UI, English, and Malayalam modes;
- responsive wrapping for long Malayalam labels and mixed scientific terms;
- adjustable content architecture through the Learning Preferences route;
- one primary task per route; no crowded dashboard;
- text-labelled controls only—no icon-only primary action;
- status is never conveyed by colour alone;
- trust information is progressive: primary status, compact source status, then an expandable **Why can I trust this?** panel;
- no autoplay, flashing, forced timers, or required animation.

The shell uses text status labels: Approved, Needs review, and Outdated. They are presentation labels and not substitutes for the future central policy.
